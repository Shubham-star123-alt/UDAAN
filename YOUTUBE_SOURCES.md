## Trust signals used
- Public YouTube video metadata: title, creator/channel, publication date and visible view count.
- Verified creator/channel indicator where it was surfaced by the current YouTube result.
- Course structure/level notes are based on the video descriptions and, for the Python course, a current Class Central course listing.

## Important
Popularity is not the same thing as teaching quality. UDAAN sorts these records by current public view count because the requested feature was to surface what is most watched. Students should use the course description, level, duration and their goal to decide whether a resource fits.
