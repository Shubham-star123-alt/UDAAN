# UDAAN — Career & Scholarship Portal v5

This build keeps the UDAAN frontend structure while expanding it into a student-first resource with source-linked education opportunities.

## v5 updates
- Added school-stage scholarships/support records: NMMS, PM YASASVI Top Class Schools, pre-matric SC/ST/PwD routes, Beedi/Cine/IOMC/LSDM pre-matric assistance, and Maharashtra Savitribai Phule scholarship for SC girls.
- Added primary/secondary school support resources including PM POSHAN, ePathshala, DIKSHA and RTE Section 12(1)(c) guidance.
- Added a school YouTube learning explorer with Class 1–12 filters. Classes 1–10 are grouped for school learning; Classes 11–12 have senior-secondary filtering.
- Added direct, source-checked YouTube learning videos plus live YouTube class-hub links for every class from 1 to 12.
- Replaced the old high-contrast control with a persistent dark/light theme toggle and a full dark visual system.
- Removed profile-building flows; saved items and application tracking remain local to the browser.

## Data note
Scheme rules, application windows and YouTube view counts change. Each entry links to its provider, government portal or verified channel, and the site tells students to verify the current notice before applying.

## Run
Use a local HTTP server: `python -m http.server 8000` and open `http://localhost:8000/`.
